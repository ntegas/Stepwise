# Stepwise — Объём работ v2 (Master Product Concept, на ревью)

Обновлено под расширенную концепцию (`/PRODUCT_CANON.md`, §1–77), которая заменяет собой прошлую 48-пунктовую версию. Главное изменение: добавился стратегический уровень (Vision → Life Areas → Life Balance), цели и активности теперь могут иметь несколько связей друг с другом, и зафиксированы жёсткие технические правила (idempotency, единый источник правды). По-прежнему без урезания до MVP — здесь весь объём.

## 1. Стратегический уровень: Vision, Life Areas, Life Balance

- **My Vision** — свободный текст про то, какой жизни хочет пользователь. Опционально, можно не заполнять вообще. Можно писать общий Vision или отдельно по сфере жизни.
- **Life Areas** — сферы жизни (Health, Finance, Career, Relationships, Development, Lifestyle и т.д.), полностью настраиваемые: создать свою, переименовать, удалить, поменять порядок, иконку.
- **Life Plan** — стратегический экран: Vision + сферы + цели внутри каждой. Не ежедневный экран.
- **Life Balance** — куда реально уходит внимание, считается автоматически из данных. Четыре отдельных показателя на сферу (не смешиваются в один процент): Attention (сколько времени/действий), Execution (% выполнения плана), Goal Progress (движение целей), Trend (рост/падение относительно прошлого периода).

## 2. Экраны приложения (24 штуки)

**Основные (нижняя навигация):** Today, Goals, Plan, Progress.

**Второстепенные:** My Vision, Life Plan, Life Area, Goal Details, Activity Details, Task Details, Habit Details, Project Details, Session Details, History, Personal Progress History, Skills, Weekly Review, Inbox, Search, Archive, Quick Add, Settings, Auth, Onboarding.

Goals-экран имеет два режима просмотра: по сферам жизни (Life Plan) или обычным списком (All / Active / Paused / Completed).

## 3. Цели (Goals)

- 7 типов со своей математикой: Cumulative, Quantity, Distance, Financial, Target Value (движение к цифре, не накопление), Frequency, Percentage/Project.
- Быстрое создание: название + цель + дедлайн → готово. Остальное («More options»): сфера жизни, описание, приоритет, milestones, проект, метрика, расписание, категория, заметки.
- **Статус цели — отдельная система от статуса выполнения задач:** Active, Paused, Completed, Archived. Paused — это не провал и не отмена, а честная временная пауза.
- Milestones — этапы для сложных целей, опциональны.
- Projects — группировка задач под целью, опциональны.

## 4. Задачи, Inbox, Overdue

- Task — конкретное действие. Быстро: название + дата → готово. Остальные поля (цель, проект, сфера, время, дедлайн, длительность, приоритет, напоминание, повтор, метрика, план/факт, статус) — опциональны.
- **Inbox / Unscheduled** — если дата не указана, задача падает сюда, а не теряется. Принцип: "сначала зафиксировать мысль, организовать потом".
- **Overdue** — отдельный блок на Today для просроченного (Complete/Reschedule/Skip/Edit), но просроченные задачи НЕ переносятся на сегодня автоматически все разом — иначе Today захламляется.

## 5. Активности, множественные связи, привычки, повторы, таймер

- Activity — постоянная деятельность (бокс, английский и т.д.), существует независимо от целей.
- **Activity может двигать несколько целей одновременно, каждую своей метрикой.** Пример: пробежка обновляет одновременно «Пробежать 500км» (по дистанции) и «100 часов бега» (по времени) — из одной and той же сессии.
- Habit — правило регулярности («как часто»), Activity — это «что». Выполнение привычки создаёт сессию активности, а не отдельную сущность. Partial работает так же, как у активностей.
- **Один механизм повторов** для Task, Activity и Habit — не три разных, чтобы не рассинхронизировались.
- Таймер опционален, всегда есть ручной ввод времени.

## 6. Выполнение и статусы

- Статусы: ✓ Done, ◐ Partial, ○ Missed, → Rescheduled, ◌ In Progress, × Cancelled — доступны через свайп/долгое нажатие, не как 6 кнопок на экране.
- Тап ✓ → Actual = Planned автоматически, без формы.
- Partial засчитывается как есть в статистику и в цель, не обнуляется.
- **Формула Execution чётко зафиксирована:** Done=100%, Partial=факт/план, Missed=0%, Cancelled не участвует в знаменателе, Rescheduled не считается Missed на исходную дату. Для неизмеримых задач: Done=100%, Partial — процент, который задаёт сам пользователь.

## 7. Календарь / План

День / Неделя / Месяц / Год. Показывает задачи, активности, привычки, дедлайны, milestones, события. Повторяющиеся элементы появляются сами.

## 8. Быстрое создание

- Quick Add (➕) почти везде, контекстно.
- **Ввод на естественном языке** как дополнительный способ: «Boxing tomorrow 19:00 for 1h» → Stepwise сам разбирает на активность/дату/время/длительность, пользователь подтверждает. Не заменяет обычные формы, а дополняет.
- Progressive disclosure — простое видно сразу, сложное («связать с целью», «повтор», «метрика», «напоминание») — по запросу.
- Smart defaults — то, что один раз указано (связь с целью, план), больше не переспрашивается.

## 9. Прогресс и аналитика

- Периоды: неделя / месяц / год / всё время — для целей, активностей, привычек и сфер жизни.
- Planned vs Actual, % выполнения, разбивка по статусам.
- Карточка активности/цели с суммами по периодам, кол-вом сессий, средними.
- Графики: тренд, calendar heatmap, стабильность, накопительный прогресс.
- Сравнение периодов («↑22% к прошлому месяцу»).
- **Pace** — темп сейчас vs нужный для дедлайна.
- **Forecast** — прогноз даты завершения (явно как прогноз, не как обещание).
- **Drill-down**: Progress → сфера жизни → активность → история сессий.

## 10. Skills

Выводятся автоматически из данных по связанным активностям/целям. Никакого ручного «+2% к навыку» после каждого занятия — это аналитическая функция, не ежедневная обязанность.

## 11. История, личный архив, еженедельный обзор

- История — редактируема, при исправлении факта всё пересчитывается автоматически (гарантируется архитектурой, не отдельным действием).
- Personal Progress History — итоги по годам и за всё время, личная история развития.
- **Weekly Review** — автоматически собранная сводка (сколько целей продвинулось, план/факт/выполнение, самая сильная/отстающая сфера, что дальше). Пользователь не составляет отчёт вручную, только читает.

## 12. Аналитика поведения и рекомендации

Наблюдения на основе накопленных данных («планируешь 5 тренировок, выполняешь 3.2», «риск не успеть к дедлайну») + конкретные предложения («добавь ~2ч/неделю»), которые пользователь сам принимает, игнорирует или редактирует.

## 13. Поиск и архив

- Global Search — по целям, активностям, задачам, проектам, привычкам, истории. Нужен по мере роста данных.
- Archive — Active/Completed/Archived для целей, проектов, активностей, привычек, чтобы не захламлять интерфейс.

## 14. Настройки

Язык (минимум ru+en, i18n-ready, без хардкода), единицы измерения и валюта (в настройках, не зашиты), уведомления, аккаунт (включая удаление), экспорт данных, приватность, тема, синхронизация.

## 15. Технические требования (обязательны, не переносятся)

- **Offline-first** — ✓ работает без сети, синхронизация при восстановлении.
- **Idempotency** — двойной тап при плохом интернете не должен задвоить результат (+1ч, а не +2ч).
- **Пересчёт при правке/удалении** — исправление или удаление сессии автоматически пересчитывает всё связанное (цель, месяц/год/lifetime, pace, forecast, life balance) — это следствие архитектуры, а не отдельная функция, которую можно забыть написать.
- **Единый источник правды** — прогресс цели и все агрегаты считаются из Sessions/Progress Events, нигде не хранится отдельное редактируемое число, которое может разъехаться с реальностью.
- Показатели Life Area (Attention/Execution/Goal Progress/Trend) всегда отдельные, никогда не смешиваются в один процент.

## 16. Явно не входит

Networking/CRM полностью исключены: ни контактов, ни компаний, ни отслеживания отношений, ни напоминаний написать человеку. «Relationships» как сфера жизни — это личные цели пользователя, а не CRM.

## Порядок реализации (последовательность, не сокращение)

1. Фундамент: авторизация, база данных, единый источник правды + idempotency с самого начала, Settings (язык, единицы).
2. Стратегический слой: Vision, Life Areas (нужны как контейнер для целей до того, как цели начнут создаваться массово).
3. Goals (все 7 типов, статусы Active/Paused/Completed/Archived) + Activities + Habits + единый механизм повторов + Sessions с multi-metric и multi-goal fan-out + Today.
4. Tasks + Inbox + Overdue + Quick Add (включая natural language) + Progressive disclosure.
5. Plan/Calendar.
6. Progress: периоды, Planned vs Actual, Pace, Forecast, сравнение, графики, drill-down, Life Balance.
7. Milestones + Projects.
8. Goal Impact + Skills.
9. История (редактируемая) + Personal Progress History + Weekly Review.
10. Аналитика поведения + рекомендации.
11. Search + Archive.
12. Офлайн-режим + push-уведомления.
13. Публикация: ассеты, политика конфиденциальности, тестировщики, чек-лист Google Play (`/docs/play-store-checklist.md`).
