# Stepwise — Объём работ (полное приложение, на ревью)

Этот документ — полная разбивка концепции (`/CLAUDE.md`) на конкретные экраны и функции Android-приложения. Без урезания до MVP: здесь всё, что должно быть в приложении. Раздел "Порядок реализации" внизу — это только последовательность, в которой мы физически пишем код (нельзя написать всё одновременно), а не список "что войдёт, а что нет".

Язык документа — русский, чтобы было удобно проверять. Технические доки в `/docs` — на английском (стандарт для кода), но это не мешает интерфейсу самого приложения быть мультиязычным (см. ниже).

## 1. Экраны приложения

**Основные (видны всегда, через нижнюю навигацию):**
- **Today** — фокус дня + список на сегодня + счётчик (3/5), быстрое ✓
- **Goals** — список всех целей карточками, с прогрессом
- **Plan** — календарь (день/неделя/месяц/год)
- **Progress** — статистика (неделя/месяц/год/всё время)

**Второстепенные (открываются с основных):**
- Экран цели (детали, milestones, projects, история сессий по этой цели)
- Экран активности (детали, статистика, история сессий)
- Экран задачи (детали/редактирование)
- Экран привычки (детали/редактирование)
- История (полный список сессий, редактируемый)
- Личный архив (Personal Progress History) — итоги за годы
- Экран навыков (Skills) — только просмотр
- Quick Add — всплывающая форма создания (контекстная)
- Настройки (Settings)
- Вход/регистрация (auth)
- Онбординг для новых пользователей (первый запуск — коротко объяснить принцип "Powerful underneath. Simple every day.")

## 2. Цели (Goals) — §9–13

- Создание цели: быстрое (название, цель, дедлайн) + "More options" (milestones, priority, project, category, description).
- Все 7 типов целей с собственной математикой прогресса:
  1. Cumulative (часы, накопление)
  2. Quantity (штуки, например книги)
  3. Distance (км)
  4. Financial (деньги)
  5. Target value (например вес — движение к целевому числу)
  6. Frequency (раз в неделю)
  7. Percentage / project (готовность проекта в %)
- Milestones — этапы цели (опционально, не обязательны для простых целей).
- Projects — группировка задач под сложную цель (опционально).
- Закрытие цели при достижении, с возможностью поставить следующую цель на ту же Activity без потери истории.

## 3. Активности (Activities) и Sessions — §15–19, 24

- Список активностей пользователя (бокс, английский, медитация и т.д.), с иконкой.
- Привязка активности к цели один раз ("запомненная связь") — дальше не переспрашивать.
- Recurring — расписание активности создаётся один раз (например "вторник+четверг, 19:00, 1ч") и дальше повторяется само.
- Таймер (старт/стоп) — опционально, есть и ручной ввод времени.
- Session создаётся автоматически при любом выполнении — вручную пользователь Session не заполняет.
- Одно действие пользователя → один Progress Event → автоматическое обновление Activity, Goal, всей статистики (никакого дублирующего ввода).

## 4. Задачи (Tasks) — §14, 39–41

- Быстрое создание: только название + дата.
- Полная форма (по кнопке "More options"): цель, проект, время, дедлайн, длительность, приоритет, напоминание, повтор, метрика, plan/actual, статус.
- Quick Add (➕) доступна почти везде, контекстно (например внутри активности сразу предлагает "добавить сессию этой активности").

## 5. Выполнение и статусы — §5–8, 43

- Быстрое выполнение: тап ✓ → сразу Done, Actual = Planned, без доп. формы.
- Остальные статусы через свайп/долгое нажатие/меню (не занимают экран постоянно): Partial, Missed, Rescheduled, In Progress, Cancelled.
- Частичное выполнение — можно ввести реальное количество (например, 40 из 60 минут) — идёт в статистику как есть, не обнуляется.
- Planned и Actual хранятся отдельно везде, где это применимо.

## 6. Привычки (Habits) — §22–23

- Создание привычки (например "Meditation 15 мин/день").
- Привязка к Activity и/или Goal (опционально).
- Поддержка Partial так же, как у активностей.

## 7. Календарь / План — §20–21

- Виды: день / неделя / месяц / год.
- Показывает: задачи, активности, привычки, дедлайны, milestones, события.
- Recurring-активности отображаются автоматически без ручного повторного создания.

## 8. Прогресс и аналитика — §25–33, 36–38

- Периоды: неделя / месяц / год / всё время — для целей, активностей, привычек.
- Planned vs Actual с % выполнения, разбивкой по статусам (Done/Partial/Missed/Rescheduled/Cancelled).
- Карточка активности: цель, неделя/месяц/год/lifetime, кол-во сессий, средняя сессия, среднее в неделю.
- Графики: тренд по дням/неделям/месяцам/годам, calendar heatmap, стабильность (consistency), накопительный прогресс.
- Сравнение периодов ("↑22% к прошлому месяцу").
- **Pace** — текущий темп vs требуемый темп до дедлайна (🟢 Ahead / 🔴 Behind).
- **Forecast** — прогноз даты завершения цели по текущему темпу, сравнение с дедлайном.
- Аналитика поведения — текстовые наблюдения на основе накопленных данных (например "выполняешь 91% утром и 54% вечером").
- Рекомендации — конкретные предложения на основе анализа (например "добавь 2ч/неделю, иначе не успеваешь к дедлайну"), пользователь сам решает, применять или нет.

## 9. Goal Impact и Skills — §34–35

- Ранжирование задач по влиянию на цель (High/Medium/Low), Today может поднимать важные задачи выше.
- Skills — выводятся автоматически из накопленных данных по активностям/целям, без отдельного ручного учёта.

## 10. История — §29, 36

- Полная история сессий, с возможностью открыть и исправить Actual — все связанные показатели пересчитываются автоматически.
- Personal Progress History — архив по годам и за всё время (не просто список сделанного, а история личного развития).

## 11. Настройки (Settings)

- Язык интерфейса (переключение, минимум русский + английский).
- Единицы измерения (метрическая/имперская система, валюта) — не зашиты в код, задаются пользователем.
- Уведомления (вкл/выкл, время).
- Управление аккаунтом: выход, удаление аккаунта и данных (обязательно для Google Play).
- Экспорт данных (полезно и для доверия пользователей, и как задел под будущие требования сторов).

## 12. Технические требования, не видные на экране, но обязательные

- **Мультиязычность (i18n)** — ни одного текста, зашитого прямо в код; всё через файлы переводов.
- **Работа офлайн** — можно отметить ✓ без интернета, синхронизация происходит при восстановлении связи.
- **Push-уведомления** — напоминания о задачах/привычках.
- **Многопользовательность** — приложение публичное, у каждого пользователя свои данные (уже заложено в базе данных).

## 13. Явно НЕ входит — §46

- Нет networking/CRM: ни контактов, ни компаний, ни отслеживания отношений, ни напоминаний "написать человеку".

## Порядок реализации (последовательность разработки, не сокращение функций)

Это порядок, в котором мы физически будем писать код полного приложения — каждый шаг добавляет часть готового продукта, ничего не выбрасывается:

1. Авторизация + подключение к базе + Settings (язык, единицы измерения) — фундамент, на котором строится всё остальное.
2. Goals (все 7 типов) + Activities + Sessions + Today — ядро продукта: цикл ✓ → Session → Goal.
3. Tasks + Quick Add + Progressive disclosure форм.
4. Plan/Calendar + Recurring activities.
5. Habits.
6. Progress: статистика, Planned vs Actual, Pace, Forecast, сравнение периодов, графики.
7. Milestones + Projects.
8. Goal Impact + Skills.
9. История (редактируемая) + Personal Progress History.
10. Аналитика поведения + рекомендации.
11. Офлайн-режим + push-уведомления (можно и раньше, если удобнее технически — не блокирует остальное).
12. Подготовка к Google Play: ассеты, политика конфиденциальности, набор тестировщиков, финальная проверка `/docs/play-store-checklist.md`.
